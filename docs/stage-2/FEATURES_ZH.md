# Translator 第二阶段功能清单与优先级

文档版本：1.0  
文档状态：待评审  
最后更新：2026-07-29

## 1. 优先级定义

- **P0**：第二阶段首个可用版本必须具备，缺失则不能完成核心路径。
- **P1**：首版发布前应完成，用于保证完整体验、隐私和可维护性。
- **P2**：后续增强，不阻塞首版验证。

## 3. 核心用户路径

```text
S2-M01 应用基础
  → S2-M02 全局快捷键
  → S2-M03 区域截图
  → S2-M04 截图隐私
  → S2-M05 本地 OCR
  → S2-M06 校对确认
  → S2-M07 Provider 核心
  → S2-M08 浏览器桥接
  → S2-M09 结果与发音
  → S2-M10 本地收藏
```

该路径是首个可用版本的最低闭环。

## 4. 建议实施批次

### 批次 A：技术基础验证

包含：S2-M01、S2-M03 原型、S2-M05 OCR 对比、S2-M07、S2-M08 桥接原型。

交付标准：

- 选定 Windows 技术栈；
- 验证多屏截图坐标；
- 验证至少一个本地 OCR 引擎；
- 打通桌面程序到 Chrome 插件的最小往返；
- 使用 Mock 和 Browser Bridge 完成一条翻译演示链路。

此批次应先验证高风险接口，不追求完整界面。

### 批次 B：核心可用版

包含：S2-M02 至 S2-M10、S2-M14 的 P0 部分、S2-M15 的 P0 部分。

交付标准：

- 从任意应用截图到翻译结果的完整流程；
- 可编辑 OCR 文本；
- 音标、发音和爱心收藏；
- 浏览器桥接失败可诊断；
- 原始截图不落盘、不上传。

### 批次 C：双端协作与数据

包含：S2-M11、S2-M12、S2-M13。

交付标准：

- 桌面与插件主动同步收藏；
- 合并和冲突规则有自动化测试；
- CSV 与第一阶段双向兼容；
- 设置保存有明确反馈。

### 批次 D：第一阶段收尾级发布保护

包含：S2-M14 至 S2-M17。

交付标准：

- 错误、隐私、安全、CI、安装和说明书齐全；
- 第一阶段插件回归通过；
- 生成第二阶段候选安装包与测试报告。

### 批次 E：后续增强

包含：S2-M18 至 S2-M20。

只有在核心版本稳定后再排期，不与首版同时堆叠。

## 6. 首版明确暂缓

以下内容不应借“顺便实现”进入 P0：

- 翻译次数统计；
- 自动后台同步；
- 删除同步和复杂冲突界面；
- 用户账户；
- 云端收藏；
- OCR 历史截图；
- 全文档解析；
- GPT 会员会话复用；
- 商业词典抓取；
- 自动屏幕监控；
- 多平台桌面客户端。

## 7. 阶段完成定义

第二阶段完成不等于功能能演示。只有满足以下条件才算完成：

- 核心路径在常见网页、PDF、Word 和 PPT 场景通过；
- 两个阶段可分别安装、运行和卸载；
- 原始截图不上传的要求有证据；
- 收藏同步不会覆盖或静默删除用户数据；
- 错误反馈均在当前操作窗口出现；
- 安装包、使用说明、设计方案和测试报告可独立获取；
- 所有 P0/P1 发布门槛通过。
