# 第二阶段 Batch E：共享收藏测试说明

## 配套浏览器插件

Batch E 必须使用同一测试包 `extension` 文件夹中的 Translator `1.1.0`。
加载新版插件后，直接启动同一包中的桌面程序；桌面程序会自动注册当前包的
Bridge Host，不再要求手动运行 PowerShell。Chrome 扩展页仍显示 `1.0.0` 时，
说明加载的仍是旧插件。

## 目标

- 桌面截图应用和浏览器插件使用同一个本地收藏库。
- 单词保存英文、音标、中文和首次收藏时间。
- 句子及段落按句子类型保存英文、中文和首次收藏时间。
- 主翻译界面只显示爱心和收藏入口，列表默认隐藏。
- 桌面端与插件继续使用完全相同的 Excel 友好 CSV 格式。

## 测试

1. 在桌面端翻译单词，点击空心爱心，确认变为红色实心爱心。
2. 点击 `Favorites`，确认新收藏出现在列表并包含首次收藏时间。
3. 关闭列表，确认翻译界面高度不受收藏数量影响。
4. 打开浏览器插件收藏页，确认桌面收藏同步出现。
5. 在插件收藏一个句子，重新打开桌面收藏列表，确认句子出现。
6. 桌面端导出 CSV，在 Excel 中确认五列结构清晰。
7. 修改有效 CSV 后导入，确认新增项同步到插件。
8. 导入错误格式时，确认错误显示在收藏窗口底部且窗口不假装持续处理中。
9. Native Host 未安装或断开时，确认插件仍可保存到浏览器本地，并明确提示稍后同步。
10. 同时打开桌面收藏窗口和插件收藏页：在桌面新增收藏，重新聚焦插件窗口，
    确认列表立即刷新；在插件删除收藏后重新打开桌面列表，确认删除同步。
11. 确认桌面主界面的英文框和中文框右上角分别有 `Copy`，两者复制内容互不混淆。
12. 确认设置入口显示为齿轮图标，悬停时出现 `Settings` 提示。
13. 关闭 Chrome 桥接注册项后启动桌面程序，确认程序自动恢复注册；收藏按钮显示
    `Favorites (数量)`，数字与桌面收藏窗口条目数一致。
14. 在桌面收藏窗口使用 Ctrl 选择多个不连续条目、Shift 选择连续条目，点击
    `Remove selected`，确认全部选中项一次删除且底部显示实际删除数量。
15. 不启动 Windows 程序，打开插件并等待超过 20 秒，确认翻译和浏览器收藏仍可用，
    且插件停止自动重试、显示 `Browser storage · sync paused`。
16. 在离线状态新增或删除收藏，然后启动 Windows 程序；重新聚焦插件侧边栏，
    确认无需打开收藏列表即可自动合并，并显示 `Shared with the Windows app`。
17. Bridge 可用时重新加载插件，确认启动阶段自动连接；原浏览器收藏只迁移一次，
    桌面端已经删除的条目不会被浏览器旧快照重新添加。
18. 快速连续触发窗口聚焦和可见性变化，确认只执行一个同步任务，界面仍可操作。
19. 导出 CSV，确认每行 `First saved` 只有 `YYYY-MM-DD`；重新导入该文件仍成功。
20. 单独翻译 `granted`，确认首个含义为“授予/批准”一类核心义，并显示词典生成的
    其他常见释义，而不是只显示“倘若”。
21. 删除 Native Messaging 注册项后点击插件 `Sync now`，确认收藏页显示具体失败
    原因；重新激活桌面程序后再次同步，确认注册恢复且两端收藏合并。
22. 运行 `Translator-Setup.exe`，确认无需管理员权限和 PowerShell；安装后桌面
    快捷方式可启动，Bridge 注册路径指向固定安装目录。
23. 在 Chrome 加载 `%LOCALAPPDATA%\Programs\Translator\extension`，完成浏览器
    与桌面收藏同步；运行卸载程序后确认应用和 Bridge 被移除、收藏 JSON 被保留。

## 数据位置

共享文件保存在当前 Windows 用户的：

```text
%LOCALAPPDATA%\Translator\favorites.json
```

文件不上传云端，写入采用临时文件替换，避免写入中断产生半份数据。

同步采用增量 `upsert/remove`，不会再用插件中的旧列表覆盖整份共享文件。插件
启动时只在约 20 秒内有限重试；之后只由聚焦、恢复可见、打开收藏、收藏修改或
`Sync now` 触发单次同步，不执行持续高频轮询。

24. 在 Bridge 注册缺失时点击浏览器爱心，确认爱心和本地数量立即变化，不等待 Native Messaging 失败；收藏页随后显示待同步错误。
25. 恢复 Bridge 后点击 `Sync now`，确认离线收藏合并进共享库且状态变为 `Shared with the Windows app`。
26. 翻译带音标的单词，确认浏览器音标与中文翻译字号、字重和颜色一致。
27. 在 Windows 程序中翻译单词，确认中文结果框第一行显示音标、下一行显示中文释义；翻译句子时不显示单词音标。

28. 保持 Chrome 和插件开启，让 `Translator.BridgeHost.exe` 正在运行；直接再次运行新版安装器覆盖安装，确认不再出现
    `DeleteFile failed; code 5`，安装完成后插件无需重新选择目录且 `Sync now` 可以恢复共享。
