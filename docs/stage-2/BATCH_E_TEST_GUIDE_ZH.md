# 第二阶段 Batch E：共享收藏测试说明

## 目标

- 桌面截图应用和浏览器插件使用同一个本地收藏库。
- 单词保存英文、音标、中文和首次收藏时间。
- 句子及段落按句子类型保存英文、中文和首次收藏时间。
- 主翻译界面只显示爱心和收藏入口，列表默认隐藏。
- 桌面端与插件继续使用完全相同的 Excel 友好 CSV 格式。

## 测试

1. 在桌面端翻译单词，点击空心爱心，确认变为红色实心爱心。
2. 点击 `Favorites`，确认新收藏出现在列表并包含首次收藏时间。
3. 关闭列表，确认翻译界面高度不受收藏数量影响。
4. 打开浏览器插件收藏页，确认桌面收藏同步出现。
5. 在插件收藏一个句子，重新打开桌面收藏列表，确认句子出现。
6. 桌面端导出 CSV，在 Excel 中确认五列结构清晰。
7. 修改有效 CSV 后导入，确认新增项同步到插件。
8. 导入错误格式时，确认错误显示在收藏窗口底部且窗口不假装持续处理中。
9. Native Host 未安装或断开时，确认插件仍可保存到浏览器本地，并明确提示稍后同步。

## 数据位置

共享文件保存在当前 Windows 用户的：

```text
%LOCALAPPDATA%\Translator\favorites.json
```

文件不上传云端，写入采用临时文件替换，避免写入中断产生半份数据。
