# Translator 第一阶段最终版安装与使用说明书

文档版本：1.0  
对应软件版本：1.0.0-rc.1（第一阶段最终候选版）  
最后更新：2026-07-29

## 1. 产品用途

Translator 是一款轻量、本地优先的 Chromium 浏览器扩展，用于日常英文学习。核心使用路径是：

> 在网页中选中英文 → 自动翻译 → 查看音标与中文 → 播放发音 → 收藏 → 导入或导出收藏

第一阶段不包含翻译次数统计、Windows 截图 OCR 和浏览器商店正式发布。

## 2. 运行环境

- Windows、macOS 或 Linux 桌面系统；
- 推荐 Chrome 138 或更高版本；
- Edge 可以加载同一安装包，但 Chrome 本地 Translator API 在不同 Edge 版本中的可用性可能不同；
- 浏览器必须支持 Manifest V3 和侧边栏。

受浏览器安全限制，`chrome://`、`edge://`、浏览器扩展商店以及部分内置 PDF 页面不能运行普通网页划词脚本。

## 3. Chrome 安装

1. 下载 Translator 最终测试包 ZIP。
2. 将 ZIP 解压到一个固定目录，不要直接在压缩包内打开。
3. 在 Chrome 地址栏输入 `chrome://extensions`。
4. 打开右上角“开发者模式”。
5. 点击“加载已解压的扩展程序”。
6. 选择包含 `manifest.json` 的解压目录。
7. 在扩展列表中确认 Translator 已启用。
8. 如有需要，将 Translator 固定到浏览器工具栏。
9. 刷新安装前已经打开的网页。

安装新版本或点击扩展的“重新加载”后，已经打开的网页必须刷新一次，否则旧页面不会获得新的划词脚本。

## 4. Edge 安装

1. 下载并解压同一个 ZIP。
2. 在 Edge 地址栏输入 `edge://extensions`。
3. 打开“开发人员模式”。
4. 点击“加载解压缩的扩展”。
5. 选择包含 `manifest.json` 的解压目录。
6. 刷新安装前已经打开的网页。

如果 Edge 不支持 Chrome 本地 Translator API，插件会显示可理解的不可用提示。Azure 仍然只是用户主动配置的可选备用方案。

## 5. 首次使用与本地语言包

Translator 默认调用 Chrome 管理的本地中英翻译模型。语言包不包含在插件 ZIP 中，而由 Chrome 按需下载、更新和管理。

首次翻译时：

1. 在普通 HTTPS 网页中选中英文；
2. Chrome 如果提示需要准备本地翻译模型，请允许下载；
3. 等待模型准备完成后重新选择或重试翻译；
4. 模型下载完成后，后续翻译通常在本地完成。

语言包可能因浏览器更新、磁盘空间或浏览器清理策略被移除。出现本地模型不可用提示时，按照插件提示重新准备即可。

## 6. 网页划词翻译

### 6.1 自动翻译

1. 打开一个普通网页。
2. 用鼠标选中英文单词、句子或短段落。
3. Translator 自动读取选区并在侧边栏显示结果。

插件会清理首尾空格并合并不必要的连续空白。当前单次输入上限为 5000 个字符。

### 6.2 重复查询同一内容

先取消当前选区，再重新选择相同英文。插件会把新的选择视为一次新的翻译操作。

### 6.3 右键备用入口

自动划词不可用时：

1. 选中英文；
2. 点击鼠标右键；
3. 选择 Translator 的翻译菜单。

右键入口用于网页兼容性备用，不依赖自动选择事件。

## 7. 翻译结果

结果区域会显示：

- 英文原文；
- 中文翻译；
- 内容类型（单词、句子或段落）；
- 翻译来源；
- 网页来源；
- 单词音标（词典数据可用时）。

Chrome 本地翻译是默认来源。只有用户在设置中显式开启 Azure 备用，并且本地翻译失败时，才会调用 Azure。

## 8. 发音

1. 在翻译结果中点击发音按钮。
2. 再次点击可停止播放。
3. 在设置中选择美式英语或英式英语。

发音使用浏览器或操作系统的本地语音能力，不录音，也不上传音频。

## 9. 收藏

### 9.1 添加或取消收藏

- 空心爱心表示未收藏；
- 红色实心爱心表示已收藏；
- 点击爱心可切换收藏状态。

单词和句子分别保存。段落不作为第一阶段的收藏类型。

### 9.2 打开收藏列表

点击“Favorites”按钮打开独立收藏弹窗。收藏列表默认隐藏，不占用日常翻译界面。

列表分为：

- Words：英文、音标、中文、首次收藏时间；
- Sentences：英文句子、中文翻译、首次收藏时间。

可以在收藏弹窗内删除项目。

## 10. 收藏导出

1. 打开收藏弹窗。
2. 点击“Export CSV”。
3. 浏览器下载 UTF-8 CSV 文件。
4. 文件可用 Excel、记事本或其他表格工具打开。

CSV 列固定为：

1. `Type`
2. `English`
3. `Phonetic`
4. `Chinese translation`
5. `First saved`

请保留标题行和列顺序。

## 11. 收藏导入

1. 打开收藏弹窗。
2. 点击“Import CSV”。
3. 选择 Translator 导出的 CSV 或同结构文件。
4. 收藏弹窗内会显示“正在导入”、成功数量或失败原因。

导入采用合并方式：

- 已存在的项目不会重复创建；
- 新项目会添加到本地收藏；
- 只要存在无效行，整次导入就会停止，不产生部分数据。

手动修改 CSV 时：

- `Type` 只能是 `word` 或 `sentence`；
- `English`、`Chinese translation` 和 `First saved` 必填；
- `First saved` 必须是有效时间，例如 `2026-07-29T02:42:33.626Z`；
- 包含逗号、双引号或换行的内容必须遵守 CSV 引号规则。

失败提示会直接显示在收藏弹窗内，并指出无效行号。按钮随后恢复为“Import CSV”。

## 12. 设置

设置页包含：

- 美式或英式发音偏好；
- 是否允许本地翻译失败后调用 Azure；
- Azure Translator Key；
- Azure Region；
- 清除本地数据。

保存成功后设置窗口会自动关闭。

### Azure 注意事项

Azure 是可选功能，默认关闭。没有 Azure 账号或不希望产生云服务费用时，不需要填写 Key，也不要启用备用选项。

Azure Key 保存在浏览器扩展的本地存储中，没有额外加密层。不要在公共或不可信计算机上保存个人密钥。

## 13. 隐私与本地数据

本地保存：

- 收藏的单词与句子；
- 音标、中文翻译和首次收藏时间；
- 发音偏好；
- 可选 Azure 配置。

不会上传：

- 收藏列表；
- 完整网页；
- 浏览历史；
- 截图；
- 音频；
- 分析、广告或遥测数据。

单词音标查询可能只把当前单词发送给 Free Dictionary API。只有显式启用 Azure 备用且本地翻译失败时，才会把当前选中的英文发送给 Azure。

## 14. 清除与卸载

### 清除本地数据

1. 打开设置页。
2. 第一次点击“Clear local data”进入确认状态。
3. 第二次点击确认清除。
4. 如不想清除，点击取消。

该操作清除当前浏览器配置中的 Translator 设置和收藏。

### 卸载

在 `chrome://extensions` 或 `edge://extensions` 中找到 Translator，点击“移除”。如需主动确认数据已清除，建议先执行上述清除操作。

## 15. 常见问题

### 选中文字后没有自动翻译

- 确认是普通网页，不是浏览器保护页面；
- 安装或重新加载插件后刷新当前网页；
- 先取消选区再重新选择；
- 使用右键菜单作为备用入口。

### 第一次翻译需要下载内容

这是 Chrome 管理的本地语言包，不是插件二次安装。等待下载完成后重试。当前不能把 Chrome 私有语言包直接打进插件 ZIP。

### 有音标但没有中文或发音

音标、翻译和语音是不同来源。检查错误提示后重试；确认系统有可用的英文语音。

### CSV 无法导入

错误会在收藏弹窗内显示。根据提示检查标题、列数、类型、英文、中文和首次收藏时间。

### 在一个网页可自动翻译，另一个网页不行

另一个网页可能在扩展加载前已经打开。刷新该网页。仍然不可用时使用右键菜单。

## 16. 更新版本

1. 解压新版本到新目录，或用新文件替换旧目录；
2. 打开扩展管理页；
3. 点击 Translator 的重新加载按钮；
4. 刷新所有用于划词翻译的已打开网页；
5. 收藏与设置通常保留在浏览器本地存储中；
6. 重大升级前建议先导出 CSV。
